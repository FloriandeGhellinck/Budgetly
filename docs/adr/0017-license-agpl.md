Status: accepted (2026-11-08)

## Decision

The code is licensed under **AGPL-3.0**. Anyone may use, modify and
self-host it; anyone running a modified version as a network service must
publish their changes under the same license. The author can run the hosted
service and may offer a commercial license separately.

## Consequences

- External contributions will need a CLA if dual licensing stays an option.
- A `LICENSE` file ships with the first commit.
