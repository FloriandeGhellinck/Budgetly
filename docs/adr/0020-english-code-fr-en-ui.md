# 20. English code and docs; UI in English and French

Status: accepted (2026-11-08)

## Decision

- Code, comments, docs, ADRs, glossary, commits and PRs are in **English**.
- The UI is translatable from day one with **next-intl**; it ships in
  **English and French**. More languages (e.g. Dutch) can follow.
- Default (seeded) categories are translated; user-created names are stored
  as typed.
