# Contributing

Thanks for your interest in Budgetly.

- Read [`AGENTS.md`](./AGENTS.md), [`CONTEXT.md`](./CONTEXT.md) and the
  relevant ADRs in [`docs/adr/`](./docs/adr/) before changing code.
- Open an issue to discuss significant changes first.
- PRs must pass `pnpm checks` and `pnpm test`, and use Conventional Commit
  titles.
- The project is AGPL-3.0. Contributions may require signing a CLA so the
  project can keep offering a commercial license (ADR 0017).
